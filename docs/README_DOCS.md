# Documentación de SmartPlayer

Esta carpeta contiene los documentos principales para la entrega final del proyecto:

- `MANUAL_TECNICO.md`: arquitectura del sistema, estructuras utilizadas y algoritmos implementados.
- `MANUAL_USUARIO.md`: guía funcional para usar la aplicación.
- `INFORME_COMPARATIVO.md`: análisis de eficiencia y comparación de estructuras.

Si el catedrático solicita PDF, estos archivos pueden convertirse desde Markdown a PDF usando un editor compatible o herramientas como Pandoc.
