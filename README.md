# \# SmartPlayer

# 

# Reproductor de música en Java con playlists editables, cola de reproducción,

# historial, búsqueda y visualización de estructuras de datos.

# 

# \## Características

# \- Cargar canciones MP3 desde archivos o carpetas

# \- Crear playlists editables

# \- Cola de reproducción

# \- Historial

# \- Búsqueda por estructuras de datos

# \- Visualización de árboles

# \- Reproducción con JavaFX MediaPlayer

# 

# \## Tecnologías

# \- Java

# \- Swing

# \- JavaFX MediaPlayer

# \- FlatLaf

# \- JAudioTagger

# \- Graphviz
